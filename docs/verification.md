# Проверка первого этапа

Проверено 2 ноября 2026 года на этом компьютере.

- Пять автотестов API прошли на временной SQLite. Рабочая база ими не изменяется.
- Проверка `scripts/smoke_postgres.py` прошла на настоящей PostgreSQL 17.7: поиск, запись истории, фильтр камеры, повторный запуск приложения.
- Проверено добавление события с новым автоматически выданным ID PostgreSQL; проверочная транзакция отменена.
- `node --check frontend/app.js` — успешно.
- В браузере проверены поиск ключей, сохранённая после перезапуска история, фильтр камеры «Рабочая зона», открытие синтетического видео рюкзака.
- `/api/health` возвращает `app=iskra`, `database=postgresql`, `status=ok`.
- Запуск через `scripts/start.py` проверен. Повторный запуск распознаёт уже работающий сервер.

Известное предупреждение тестовой библиотеки: Starlette предупреждает об устаревающей интеграции TestClient с httpx. Тесты проходят; на работу приложения предупреждение не влияет. Версии зависимостей сохранены в `requirements.lock.txt`.

Не проверены и ещё не реализованы: загрузка настоящего видео, распознавание предметов, живые камеры, несколько пользователей и внешнее размещение сервера.
