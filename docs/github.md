# Загрузка на GitHub

Репозиторий: https://github.com/AlexeyKobelev/kostyan

1. Дважды нажать `Publish-GitHub.cmd` в папке ТРПО.
2. Если Git попросит войти в GitHub, войти через открывшееся окно браузера. Нужен аккаунт с правом записи в репозиторий.
3. Если у Git не задан автор, ввести имя и email. Можно использовать адрес noreply из настроек GitHub.
4. Дождаться `Upload complete`. Скрипт напечатает ссылку на созданную ветку и сравнение с `main`.
5. На GitHub открыть сравнение, проверить изменения и создать Pull request. Объединение в `main` выполняется отдельно на GitHub.

Скрипт загружает исходники в отдельную ветку `iskra-backend-ДАТА-ВРЕМЯ`. Главная ветка не изменяется. Существующий README заменяется подробным описанием приложения только в новой ветке. Используется история исходного репозитория; принудительная отправка не применяется.

Поскольку `.git` первоначально создан рабочей средой помощника, скрипт передаёт Git исключение `safe.directory` только для точного пути этого проекта и только на время каждой команды. Глобальные настройки доверия Git не изменяются.

На момент проверки в репозитории был только `README.md`. Если до первой отправки там появятся другие файлы, скрипт остановится, чтобы сначала проверить совместимость.

Не загружаются: `.env` с паролем, `.venv`, файлы базы PostgreSQL, журналы, временные файлы и кэши. `.env.example` содержит пример настроек без настоящего пароля.

На другом компьютере после получения исходников нужно установить Python и PostgreSQL, создать `.venv`, затем выполнить `Setup.cmd`. GitHub хранит исходный код; сервер приложения там автоматически не запускается.

Запуск файла отправляет код на GitHub. Само наличие этого файла ещё не означает, что код уже загружен.
